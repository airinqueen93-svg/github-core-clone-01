DEVILCUPS Forge — a GitHub-compatible git forge in pure TypeScript (Node 22, standard library only, no dependencies, no git binary at runtime). One process serves git smart-HTTP protocol v2 and v0 (clone, push, shallow fetch, deepen), a GitHub REST v3 surface (repos, branches, commits, contents, issues, labels, comments, pull requests with real merges), a GraphQL v4 subset matching the gh CLI documents, and an MCP endpoint. Git objects, packfiles (including delta resolution), tree merges and file diffs are implemented from scratch.

## Run it

```sh
node main.ts
```
